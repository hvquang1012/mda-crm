Vì sao chuyển khỏi Netlify (9/2026)

Gói miễn phí Netlify hết lượt trong tháng thì dừng cập nhật trang chính: web vẫn chạy nhưng kẹt ở bản cũ. Cloudflare Pages không giới hạn băng thông, 500 lần cập nhật/tháng, và domain đã nằm sẵn ở Cloudflare.

Các bước thực hiện

1

Tạo project Pages nối với GitHub.

dash.cloudflare.com → Workers & Pages → Create → tab Pages → Connect to Git → cấp quyền GitHub → chọn repo mda-crm.

2

Cấu hình build.

TrườngGiá trị
Production branchmain
Framework presetNone
Build command(để trống)
Build output directory/

Bấm Save and Deploy. Khoảng 1 phút sau có địa chỉ dạng mda-crm.pages.dev — mở thử, đăng nhập được là xong.

3

Chuyển tên miền sang Pages.

DNS → Records: xoá bản ghi tiendo cũ (CNAME trỏ Netlify). Rồi vào project Pages → Custom domains → Set up a custom domain → gõ tiendo.noithatminhduc.com → Activate domain. Cloudflare tự tạo lại bản ghi và tự bật HTTPS.

4

Kiểm tra.

Đợi vài phút, mở https://tiendo.noithatminhduc.com bằng tab ẩn danh. Từ nay mỗi lần merge PR vào main, Cloudflare tự cập nhật trong ~1 phút (xem ở tab Deployments của project Pages).

Sau khi domain chạy

Không cần làm gì thêm ở phía Supabase hay code — chỉ đổi phần đầu của các link đã gửi.

Link Zalo cho thợ, đội trưởng, chủ nhà đổi từ:

zippy-douhua-7a4098.netlify.app/crew.html?t=... (Netlify cũ — kẹt bản cũ)

sang:

tiendo.noithatminhduc.com/crew.html?t=...

Token (phần ?t=...) giữ nguyên — token nằm trong database, không phụ thuộc domain đang dùng.

Domain gốc noithatminhduc.com không bị thay đổi ở bước nào trong hướng dẫn này — chỉ thêm một bản ghi CNAME mới cho subdomain tiendo.
